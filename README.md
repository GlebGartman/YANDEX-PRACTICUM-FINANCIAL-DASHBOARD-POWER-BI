# 📊 Анализ финансовых показателей пользователей в Power BI

Проект по анализу финансовых показателей пользователей в Power BI с разбивкой по городам. Выполнены подготовка данных в Power Query, настройка модели данных, создание вычисляемых столбцов и мер DAX, а также разработка интерактивных визуализаций для исследования доходов, баланса и распределения пользователей

---

# 📌 Постановка задачи

В рамках проекта необходимо разработать интерактивный аналитический отчет в Power BI для исследования финансовых показателей пользователей

Отчет должен помогать:

- анализировать средний баланс пользователей по городам
- сравнивать доходы пользователей различных городов
- отслеживать изменение доходов по месяцам
- анализировать структуру доходов с помощью различных типов визуализаций
- сравнивать вклад каждого города в общий доход
- анализировать распределение пользователей между городами
- исследовать финансовые показатели с использованием интерактивной фильтрации

---

# 📂 Используемые данные

В проекте используются три взаимосвязанные таблицы:

- **transactions** — сведения о финансовых операциях пользователей
- **users** — информация о пользователях
- **cities** — справочник городов

---

# 🛠 Используемые технологии

- **Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel**

---

# ⚙ Подготовка данных

Перед построением аналитического отчета данные были подготовлены с помощью **Power Query**

В ходе подготовки данных выполнены следующие действия:

- импорт данных из Excel
- переименование столбцов
- создание столбца **Баланс**
- построение модели данных
- настройка связей между таблицами

Подготовка данных обеспечивает корректную работу модели и автоматическое применение всех преобразований при обновлении источника

---

# 🧩 Модель данных

Модель данных состоит из трех связанных таблиц:

- **transactions** — таблица финансовых операций
- **users** — таблица пользователей
- **cities** — таблица городов

Связи между таблицами позволяют анализировать доходы, расходы и баланс пользователей в разрезе городов

---

# 📐 Вычисляемые столбцы

## Баланс

В Power Query был создан столбец, отражающий разницу между доходом и расходом пользователя

```text
Баланс = Доход - Расход
```

## Баланс, тыс

Для отображения баланса в тысячах рублей был создан вычисляемый столбец на языке DAX

```DAX
Баланс, тыс = ROUND(DIVIDE([Баланс], 1000), 2)
```

Столбец переводит значение баланса из рублей в тысячи рублей и округляет результат до двух знаков после запятой

---

# 📏 Меры

## Средний баланс, тыс.

Для расчета среднего баланса пользователей была создана мера

```DAX
Средний баланс, тыс = AVERAGE(transactions[Баланс, тыс])
```

Мера вычисляет средний баланс пользователей и автоматически пересчитывается в зависимости от выбранного города, периода и контекста визуализации

---

# 🎛 Фильтрация данных

Для интерактивного анализа данных в отчете настроен следующий фильтр:

- **Дата**

Фильтр позволяет анализировать финансовые показатели за выбранный период и автоматически обновляет все визуализации отчета
