# YANDEX-PRACTICUM-FINANCIAL-DASHBOARD-POWER-BI
Проект по анализу финансовых показателей пользователей в Power BI с разбивкой по городам. Выполнены подготовка данных в Power Query, настройка модели, расчет показателей на языке DAX и построение интерактивных визуализаций по доходам, балансу и количеству пользователей
